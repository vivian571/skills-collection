# Skills Collection · 技能收藏集

收集各种 skills 并按分类整理的目录项目。每个 skill 一张卡片，登记它的分类、来源、许可、位置和调用方式；总索引 [CATALOG.md](CATALOG.md) 由脚本自动生成。

## 为什么用卡片制

只登记元信息，**不复制技能本体**。技能本体只存一份（自建的在 `~/workspace/custom-skills/`，外部的在上游仓库），卡片指向它——避免两份文件各改各的、日久漂移。

## 分类

| 分类 | 装什么 |
|---|---|
| ✍️ 写作与出版 | 选题、写作、润色、发布管线 |
| 🔍 分析与诊断 | 看透问题、轨迹/上下文/工具链分析 |
| 🛠️ 逆向工程 | APK / JS / 网站流量逆向 |
| 🎬 视频与视觉 | 手绘视频、技术图解 |
| 🧠 行为与决策 | 谈判、决策、说服、习惯 |
| 📚 教育与学习 | 学科解题、教学内容生成 |
| 🌐 外部收藏 | 他人开源的技能合集与单个技能（只登记，注明上游与许可） |

新分类随时加：在 `cards/` 下新建目录即可，索引脚本按卡片上的「分类」字段自动归组。

## 来源三类

- **自建**：为自己工作流原创的技能。
- **改编**：基于他人项目蒸馏/适配，卡片注明上游与原许可。
- **外部**：他人项目原样收藏，只登记链接，不搬运内容。

## 每日采集

这个项目每天自动从两个源头收新货（cron `daily-skills-collect`，上午十点多跑）：

- **发现**：X（推特）上分享 skills 的帖子与报道（无直连 API，走网页搜索），外加 GitHub 按 topic/关键词的新仓库与热榜。
- **验真**：一律回到 GitHub 一手核对——仓库存在、许可、最近更新、树里是否真有 SKILL.md。验不过的不写卡，只记进候选名单（`state/seen.md`，本机状态，不进仓库）。
- **入库**：验真的新货按模板写成卡片放进「外部收藏」，刷新 CATALOG，并发一份当日简报；没有新发现的日子不发消息。

边界：只收藏登记，**不自动安装、不运行**任何收来的 skill；要不要装、装哪个，人工决定。

## 怎么新增一张卡

1. 复制 [templates/skill-card.md](templates/skill-card.md) 到 `cards/<分类slug>/<技能名>.md`，按模板填好。
2. 跑 `python3 scripts/build_catalog.py` 刷新 CATALOG.md。
3. 脚本会校验必填字段（分类 / 来源 / 一句话），缺了会报出来。

详见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 许可

本目录项目只收集元信息卡片，不含技能本体。每个 skill 的许可以其卡片标注为准（例如改编自 Supervisor-Skills 的写作技能为 CC BY-NC-SA 4.0，仅个人非商用）。引用或分发某个技能前，先看它的卡片。
