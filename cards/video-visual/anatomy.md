# anatomy（等距技术图解）

- 分类: 视频与视觉
- 来源: 外部
- 许可: MIT
- 位置: ~/workspace/custom-skills/local-anatomy/
- 调用: 「用 anatomy 画一张 XX 原理图」
- 一句话: 把一个技术概念画成精细的交互式等距 SVG 实物图（仪表、机柜、锁具式的物理对象）。

## 说明

Linear 风格的高级技术绘图：多零件、四阶明暗、正确绘制顺序、带标题/提示/实时读数的画框，可加同透视的 WebGL 着色效果（火、水、光）。框架无关或 React 均可。需要 Node 20.10+。

## 边界

与手绘视频风格互补、不互相替代。成品可按需发布到 Anatomy 社区画廊——发布前先确认。
